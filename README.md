# Todo App (Vite + React + Tailwind)

แอปรายการงาน UI ภาษาไทย เก็บข้อมูลใน React state เท่านั้น (รีเฟรชแล้วข้อมูลหาย)

## เริ่มใช้งาน
```bash
npm install
npm run dev      # เปิด http://localhost:5173
npm run build    # สร้างไฟล์ production ในโฟลเดอร์ dist
npm run preview  # ดูผล build
```

## เทคโนโลยี
React 19, Vite, Tailwind CSS v4, lucide-react
